3. Para continuar: “Agora analise o comprimento da mesma foto”.

Como funciona o projeto — lembrete para apresentar

O navegador reconhece a voz e a aplicação roda localmente no Acer. O backend Python/FastAPI envia a fotografia pela internet à API da Gemini, que analisa e devolve o resultado. O modelo de IA roda na nuvem do Google; a VPS não participa da execução local.

Projeto acadêmico · Classificações visuais estimadas; não substituem avaliação profissional.
